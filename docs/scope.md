# Scope — SMB Security Baseline

## In scope

- Account inventory + MFA enforcement across Google Workspace / M365, banking, payroll, CRM, hosting, social.
- Password manager rollout (1Password or Bitwarden) with team training.
- Backup audit: what's backed up, how often, last successful restore test.
- Endpoint baseline: disk encryption, OS update policy, basic EDR if needed.
- Incident response playbook (1-page) + tabletop exercise with the team.
- Vendor list + SBOM-lite for any custom software you ship to customers.
- Security posture one-pager for prospect questionnaires.

## Out of scope

- Full SOC2 Type II audit (we'll prep you, but a CPA firm signs the report).
- Penetration testing (we coordinate with a partner firm).
- HIPAA / PCI level-1 deep compliance (separate engagement).

## Change requests

Anything outside the above is handled via a written change order. We will not start unscoped work without one — protects you from surprise invoices and protects us from scope creep.

## Assumptions

- Decision-maker is reachable within 1 business day during the engagement.
- All access (logins, admin invites) provided within the first 48 hours of kickoff.
- Engagement is paused — not extended — if access is delayed beyond 5 business days. Day count resumes when access is restored.

## Acceptance criteria

Each deliverable in [`deliverables.md`](./deliverables.md) has a checkbox. Engagement is complete when all are checked off and you have signed the handoff doc. Optional 30-day warranty applies to anything we built that regresses without you changing it.
